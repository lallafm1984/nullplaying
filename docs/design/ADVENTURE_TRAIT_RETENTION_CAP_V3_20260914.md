# 모험 특성 규칙 v3 — 3일 보호·최대 7개

2026-09-14 사용자 요청 반영. 최대 보유 수는 후속 요청에 따라 **5개에서 7개로 변경**했다. 현재 루트 소스 변경이며 배포는 별도다.

## 적용 규칙

- 특성 획득 후 **72 모험 활동시간** 동안 `LOST`와 `REPLACED`를 모두 차단한다.
- 72시간이 지나면 기존 소멸 조건(흔들림 상태, 부정 근거 6개 이상·3개 맥락 이상, 흔들림 시작 후 24활동시간)을 만족할 때 소멸한다. 72시간 경과 자체로 삭제하지 않는다.
- 보호 중에도 기존 규칙에 따른 흔들림·회복은 가능하며, 보유 효과는 계속 적용된다.
- 최대 **7개**까지 신규 획득한다. 7개에서는 8번째 특성 추첨을 하지 않는다. 자연 소멸로 빈자리가 생기면 다음 적격 판정부터 획득할 수 있다.
- 정확히 7개 상태에서도 보호 기간을 지난 기존 특성과 반대 특성의 1:1 교체는 허용한다. 교체된 새 특성은 다시 72활동시간 보호를 받는다.
- 예전 저장에 이미 8개 이상이 있으면 강제 삭제하지 않는다. 소멸 조건으로 7개 이하가 될 때까지 신규 획득·교체를 막는다. 이는 기존 보유 특성의 보호를 지키기 위한 저장 호환 예외이며 신규 상태에서는 7개를 초과하지 않는다.

## 저장·시간 처리

- 별도 `retentionStartedAtByTrait` 시계를 저장한다. 기존 `acquiredAt` 표시 시각을 변경하지 않는다.
- 미충전 오프라인 휴지 구간만큼 이 시계도 이동시킨다. 달력상 방치 시간이 보호 기간을 소진하지 않는다.
- 회복 후 안정 시계가 재설정되어도 획득 보호 시계는 재시작하지 않는다.
- 이전 저장에 보호 시계가 없으면 휴지 시간을 이미 반영한 기존 안정 시계를 사용한다. 그것도 없으면 현재 행동 시각에서 시작해 보수적으로 보호한다. 기존 안정 시계가 회복 때문에 늦어진 경우 보호가 더 길어질 수 있다.
- v2 근거 정리는 버전 1 저장에만 적용한다. v2에서 v3으로 올라올 때 정상 근거를 다시 제거하지 않는다.
- 새 상태·획득·변화 기록은 규칙 버전 3을 사용한다. 과거 보유 기록의 출처 버전은 유지한다.

## 결투장 안내

`ArenaGuide.kt`의 한국어·영어·일본어 안내에서 로컬 도전자의 레벨과 최근 전적에 따른 강도 조절 문장을 제거했다. 해당 줄은 캐릭터의 레벨과 능력치를 사용한다는 설명만 남긴다. 매칭·전투 로직은 변경하지 않았다.

## 검증

- 72시간 직전 C02 소멸 차단, 정확히 72시간에 조건부 소멸.
- 보호 만료만으로 소멸하지 않음.
- 7개 보유 시 8번째 획득 차단 및 기존 보유 항목 보존.
- 보호 기간을 우회하는 반대 특성 교체 차단, 만료 후 1:1 교체와 새 보호 시계 설정.
- 자연 소멸 후 빈자리 재획득.
- 저장 복원·반복 초기화·1000시간 휴지에서도 보호 시계 유지.
- 이전 초과 보유 저장의 보존 및 추가 획득 차단.
- 6직업 × 4시드, 각 168활동시간의 자연 모험에서 최대 7개와 소멸·교체 최소 보유 72시간을 매 정산 검증.
- 실제 카탈로그의 위험 감수 접근으로 C02가 24시간에 흔들리고 72시간에 소멸하는 통제 검증.
- 기존 특성·저장소·결투장 안내 회귀 검증. 상세 로그와 최종 시뮬레이션 집계는 `output/trait-retention-v3/20260914/`에 저장.

이전 v2의 특성 수·소멸률 보고서는 당시 규칙의 역사적 분석이다. 이번 보호 기간·보유 상한을 적용한 결과와 혼동하지 않는다. 출시용 빌드·설치·Play 배포·운영 DB 변경은 수행하지 않았다.
