# 모험 특성 획득 규칙 v2

작성: 2026-09-14. 상태: **현재 루트 소스 구현 및 로컬 검증 완료. 출시용 AAB·기기 설치·Play 배포·운영 DB 적용은 수행하지 않음.**

## 수정 목적과 확인된 원인

같은 자동 모험을 진행한다는 사실만으로 모두 같은 특성을 획득하는 현상을 줄인다. 2026-09-11 기록의 59/59 C02는 과거 운영 스냅샷 기준선이며 오늘 다시 조회한 값이 아니다.

1. 모든 일반 전투가 C02 긍정/C01 부정을 생성했다.
2. `freshPositive`만 후보로 비교해 고빈도 행동이 형성 기회를 선점했다.
3. 장비 자동 비교·사용과 전투 경험치 수령도 L05/S05/G03 등으로 편중을 옮기는 원인이었다.
4. 반대 근거가 4개 쌓일 때마다 미보유 후보의 8시간 시계를 지워 다양한 사건 행동은 거의 성숙하지 못했다.
5. 귀환 횟수를 맥락 ID에 넣어 같은 상점 행동도 서로 다른 경험으로 취급했다.

실제로 충족한 획득 조건 안에서 기회를 고르게 제공한다. 조건 없는 특성 배분이나 보유 특성 강제 재선정은 하지 않는다. 모든 특성의 실제 획득률이 1/40이 되는 규칙은 아니다.

## 공통 형성 계약

- 특성별 최근 12개 근거 중 최근 **48 신뢰 활동시간** 이내의 근거를 비교한다.
- 긍정 근거의 같은 맥락은 최대 4개로 계산한다. 장비 자동 비교·사용·장기 사용은 맥락이 달라도 합쳐 최대 4개이며, 반대 특성의 부정 근거를 만들지 않는다. 자동 장비 근거는 저장 창에서도 최대 4개만 유지해 사건 행동을 밀어내지 않는다. 같은 원본 사건에서 실제 접근법과 충돌하면 실제 접근법을 우선한다.
- 유효 긍정 점수 8 이상, 서로 다른 실제 맥락 3개 이상, 부정 근거 3개 이하, 형성 시작 후 8 활동시간 이상이어야 한다. 근거가 모두 오래되어 사라지면 형성 시계를 다시 시작한다.
- 부정 근거가 잠깐 늘어도 형성 시계 자체를 없애지 않는다. 현재 창이 다시 위 조건을 충족해야 후보가 된다.
- 매 판정에 현재 사건 외의 누적 적격 후보도 모두 참여한다. 긍정/부정 비율, 맥락 다양성, 근거 원인 군 다양성으로 가중치를 계산한다.
- 가중치 = 정규화 긍정 비율(0–100) + 맥락 수(최대 4) × 5 + 원인 군 수(최대 3) × 5. 적격 후보 중 저장된 시드로 가중 추첨한다. 목록은 ID순으로 정렬해 저장 맵 순서에 영향을 받지 않는다.
- 적격 후보가 있을 때 최대 30 활동분마다 기존 25% 형성 판정을 한다. 성공 후 기존 24 활동시간 공통 쿨다운을 유지한다. 전투 횟수만 늘려 추첨을 연속 시도할 수 없다.
- 획득 기록의 이유는 선택된 후보의 실제 최근 긍정 근거를 사용한다. 현재 판정 계기가 다른 행동이어도 예외나 잘못된 이유가 생기지 않는다.
- 보유 수 때문에 신규 형성을 막지 않는다. 반대 특성의 동시 보유 금지, 약화·회복·소멸·교체의 기존 시간 보호는 유지한다.

## 기존 저장과 시간 보호

- 상태와 새 획득·변화 기록에 `acquisitionRulesVersion=2`를 저장한다. 기존 보유 특성과 과거 기록은 기본값 1로 읽어 출처를 유지한다.
- 업데이트 시 기존 특성 ID·획득 시각·효과를 삭제하거나 다시 뽑지 않는다. 기존 C02 보유자는 계속 C02를 보유하며, 이후 새 규칙의 행동을 통해 다른 특성도 획득한다.
- 기존 자동 전투 등급 근거, 전투 경험치 수령 근거, 자동 장비 행동의 부정 근거만 제거한다. 처리 중인 근거도 같은 규칙으로 정리한다.
- 예전 근거의 누락된 시각은 저장된 현재 행동 시작 시각으로 보완해 무기한 남지 않게 한다. C01/C02의 과거 형성 시작점은 제거한다.
- 추가 필드는 기본값이 있는 직렬화 필드다. Room 버전·기존 저장 스키마·라이브 DB를 변경하지 않는다.
- 미충전 오프라인 휴지 구간만큼 근거 시각과 형성 판정 시계도 함께 이동한다. 휴지 시간이 형성이나 재추첨 기회를 만들지 않는다.
- 전투·보상 RNG는 소비하지 않고 특성 전용 저장 시드로 계산한다.

## 로컬 검증

`testOfflineQaUnitTest`에서 특성 엔진·경계·활동시간·의미 신호·생애 기록·표시와 저장소 회귀 120개 통과. 24시간 자연 모험의 일괄 정산과 10분 단위 분할 정산·주기적 저장 복원에서 전체 게임 상태와 이벤트 목록이 동일함을 검증했다.

자연 자동 모험 코호트: **6개 직업 × 시작 레벨 1/20/100 × 8개 시드 = 144캐릭터**, 각 48시간, 합계 6,912 캐릭터·활동시간. 각 직업/레벨에서 4개 시드는 관계 명단을 제공하고, 4개는 명단 없이 진행. 레벨 100은 미궁 깊이 100에서 시작한다. 조건을 강제로 채우지 않고 실제 엔진의 사건·장비·전투 흐름으로 측정했다.

- 144/144가 48시간 안에 첫 특성을 획득.
- 최초 획득 **16종**, 48시간 전체 획득 **26종**.
- 최다 C05 34/144 = **23.6%**.
- 시작 레벨 1 최고 15/48 = **31.3%**, 레벨 20 최고 13/48 = **27.1%**, 레벨 100 최고 11/48 = **22.9%**.
- 8시간 전 획득 및 반대 특성 동시 보유 0건.
- 등급을 바꿔 가며 의무 전투만 300회 반복한 테스트에서 C01/C02 형성 근거와 신규 획득 0건.
- C01/C02 각각 전투 직전의 실제 접근에 3개 이상 맥락이 존재하며, 일반 위험 사건은 해당 근거를 생성하지 않음.
- 자동 장비만 반복한 경우 L05 근거 최대 4개, L06 부정 근거와 L05 획득 0건.
- 오래된 후보·단일 맥락 차단, 현재 행동 외 후보의 획득 및 이유 보존, 저장 복원, 휴지 시간에 의한 추가 추첨 차단을 검증.
