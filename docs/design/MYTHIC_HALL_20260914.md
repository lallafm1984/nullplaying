# 신화의 전당 — 2026-09-14

## 적용한 계약

- 아이템 → 장비 → 장착 장비 제목 오른쪽에 우측 정렬 버튼. 기존 모험가 랭킹과
  `CompactRecordEntryMenu`를 공유한다. 버튼에는 제목만 표시하며 보조 문구는 없다.
- 기존 랭킹 페이지 전환 애니메이션과 상단 바, 배경, 카드 규격을 사용한다.
  최상단·내 순위 버튼과 개인 순위 카드는 제공하지 않는다.
- 매시 정각 이전 서버 접수 기록에서 획득 시각 내림차순 최신 100개만 노출한다.
  같은 시각은 event UUID 내림차순으로 고정한다. 추가 페이지와 더 보기는 없다.
  늦게 업로드된 기록은 다음 정각부터 대상이며 재전송은 최초 기록을 변경하지 않는다.
- 현재 +5는 신화 희귀도이다. 실제 장비 드롭의 즉시 장착/가방 양쪽 경로를 기록한다.
  모험 사건과 특성 추가 보상도 같은 드롭 경로를 거친다. 상점은 최대 +3이므로 제외된다.
  가방에서 다시 장착하는 행위는 재획득으로 기록하지 않는다.
- `SimpleGameState.mythicDiscoveries`는 캐릭터별 최신 100개의 내구성 있는 전송 원본이다.
  판매/장비 교체와 무관하게 저장되며, 기본값이 빈 목록이므로 기존 세이브와 호환된다.
  과거 보유 장비를 추정해서 소급 등록하지 않고 업데이트 후 획득부터 기록한다.
- 전경에서 기록 변경 시 자동 전송하며, 전경 진입/정기 동기화에서도 재시도한다.
  모든 캐릭터 슬롯을 포함하며 성공 페이로드 해시를 저장한다. 전송 실패가 게임 기록을
  지우지 않는다. 기록 UUID는 캐릭터 ID와 획득 일련번호에서 생성되어 재전송 시 동일하다.
  임시 기기 시간을 신뢰 시간으로 교정할 때 로컬 획득 시각도 재조정한다.
- 인증 사용자 RPC만 허용하고 테이블 직접 접근은 차단한다. 기존 공개 랭킹의 숨김 및
  대체 이름 정책을 읽기 시 적용한다. 계정 삭제는 FK cascade로 해당 기록도 제거한다.
- 클라이언트에서 발생하는 오프라인 획득 기록으로, 서버가 전투/드롭을 재현해 인증하는
  구조는 아니다. 이 기록은 금화·경험치·아이템 등 경제적 보상의 근거가 되지 않는다.

## 한국어·영어·일본어

| 언어 | 제목 | 설명 |
| --- | --- | --- |
| 한국어 | 신화의 전당 | 수많은 여정 속에서 빛난, 신화의 기록. |
| 영어 | Hall of Myths | Mythic treasures. Extraordinary journeys. |
| 일본어 | 神話の殿堂 | 幾多の旅路に輝く、神話の記録。 |

갱신 안내, 뒤로가기 접근성 이름, 로딩/빈 목록/오류/재시도도 세 언어를 지원한다.
장비명은 기존 `GameNameLocalization`으로 수신 기기의 앱 언어에 맞춰 조합한다.
직업과 부위도 기존 번역을 사용하며 사용자 이름은 번역하지 않는다.
실제 장비 카탈로그를 사용하는 100개 오프라인 예시로 세 언어 진입 화면과 팝업을 검수했다.
영어·일본어 팝업 UI 계층에서 미번역 한국어가 없는 것도 확인했다.
