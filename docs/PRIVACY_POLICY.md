# NULL PLAYING 개인정보처리방침

- 시행일: 2026년 8월 26일
- 최종 수정일: 2026년 8월 31일
- 대상 앱: NULL PLAYING(구 AlarmQuest), Android 패키지 `com.nullplaying`
- 개인정보처리자: 4LTree(포엘트리)

4LTree(이하 "개발자")는 NULL PLAYING(이하 "앱")을 이용하는 동안 어떤 정보가 기기에 저장되고, 어떤 정보가 외부 서버로 전송되며, 이를 어떤 목적으로 처리하는지 이 방침을 통해 안내합니다.

앱은 이메일, 전화번호 또는 소셜 로그인을 요구하지 않으며 사용자 대면 계정을 만들지 않습니다. 다만 앱을 처음 실행하면 서버 기능을 위해 설치 단위의 Supabase 익명 인증 사용자와 임의 식별자가 내부적으로 자동 생성됩니다. 익명 식별자와 연결된 정보도 이용자 또는 설치와 다시 연결될 수 있으므로 이 방침의 보호 대상에 포함합니다.

## 1. 처리하는 정보

### 1.1 기기에만 저장되는 정보

다음 정보는 앱 기능을 제공하기 위해 기기 내부에 저장되며, 아래 1.2에 별도로 적은 일부 요약 항목을 제외한 전체 저장 데이터는 개발자 서버로 전송되지 않습니다.

- 캐릭터별 전체 게임 저장 데이터: 능력치, 장비, 가방, 스킬, 퀘스트, 전투 및 진행 상태
- 계정 공용 진행, 앱 언어, 알림 설정, 공지 확인 기록
- 오프라인 모험 및 보상형 광고 보상 처리 상태
- 서버 전송 실패 시 재시도하기 위한 제한된 임시 대기열과 랭킹 캐시

Android 시스템 백업과 기기 간 전송은 비활성화되어 있습니다. 따라서 앱 삭제, 앱 데이터 삭제 또는 기기 분실 시 로컬 데이터는 복구할 수 없습니다.

### 1.2 Supabase로 전송되는 정보

앱은 계정 인증, 랭킹, 서비스 운영 및 이용 현황 집계를 위해 다음 정보를 Supabase로 전송합니다.

| 구분 | 처리 항목 |
| --- | --- |
| 익명 인증 | 설치 단위 익명 사용자 UUID, 액세스 토큰, 갱신 토큰 |
| 기기·앱 프로필 | 기기 시스템 로캘에서 얻은 국가 코드와 언어 코드, 시간대, Android 플랫폼, 앱 버전과 버전 코드, OS 버전, 기기 제조사와 모델, 마지막 접속 시각 |
| 랭킹 | 캐릭터 UUID, 슬롯 번호, 이용자가 입력한 캐릭터 이름 또는 별명, 직업, 레벨, 전투력, 달성·갱신 시각 |
| 세션·진행 요약 | 이벤트 UUID, 세션 종료 시각과 종료 사유, 활성 슬롯, 캐릭터 레벨과 전투력, 누적 막 수와 처치 수, 앱 버전, 기기 모델 |
| 네트워크·보안 정보 | 서비스 접속 과정에서 처리될 수 있는 IP 주소, 요청 시각 및 보안·오류 로그 |

국가 코드는 IP나 GPS가 아니라 Android 기기의 시스템 로캘 설정에서 가져온 추정값입니다. 앱은 정밀 위치 권한을 요청하지 않습니다.

랭킹 화면에는 캐릭터 이름 또는 별명, 직업, 레벨, 전투력, 순위 및 달성 시각이 다른 이용자에게 공개될 수 있습니다. 익명 사용자 UUID, 기기 정보와 세션 기록은 랭킹에 공개하지 않습니다.

### 1.3 Google Mobile Ads가 처리하는 정보

앱은 배너 광고와 보상형 광고를 제공하기 위해 Google Mobile Ads(GMA Next-Gen SDK) 및 AdMob을 사용합니다. Google의 공식 공개 내용에 따르면 이 SDK는 기본적으로 다음 정보를 수집하고 Google과 공유할 수 있습니다.

- IP 주소와 이를 통해 추정되는 대략적 위치
- 앱 실행, 탭, 광고 또는 동영상 조회 등 제품 상호작용
- 앱 시작 시간, 멈춤 현상, 에너지 사용량 등 진단 정보
- Android 광고 ID, 앱 세트 ID 및 적용 가능한 기타 기기·계정 식별자

이 정보는 광고 제공·측정, 분석, 빈도 관리, 사기 및 무효 트래픽 방지에 사용될 수 있으며 전송 구간에서 암호화됩니다. 앱은 실행할 때마다 Google User Messaging Platform(UMP)으로 동의 상태를 갱신하고, 적용 지역에서 필요한 동의 폼을 마친 후 광고 요청 가능 상태인 경우에만 Google Mobile Ads를 초기화합니다. 개인정보 옵션 재진입이 필요한 이용자에게는 설정 화면에 “광고 개인정보 선택” 진입점을 표시합니다. 이용자는 Android 설정에서 광고 ID를 재설정하거나 삭제할 수 있습니다.

### 1.4 Firebase Remote Config가 처리하는 정보

앱은 오프라인 모험 최대 저장 시간과 충전 시간을 원격으로 조절하기 위해 Google Firebase Remote Config를 사용합니다. 이 SDK와 필수 의존성인 Firebase Installations는 설치 식별자(Firebase Installation ID), 국가·언어 코드, 시간대, 플랫폼·OS·SDK 버전, Firebase 앱 ID 및 패키지 이름을 처리합니다. 설정 제공과 Firebase 서비스의 유지·개선을 위한 정보이며 HTTPS로 전송됩니다. 캐릭터 이름과 전체 게임 저장 데이터는 이 기능으로 Firebase에 보내지 않습니다. Firebase Authentication과 Google Analytics SDK는 이 기능을 위해 추가하지 않습니다.

### 1.5 개발자가 의도적으로 수집하지 않는 정보

앱은 다음 정보를 직접 요구하거나 의도적으로 수집하지 않습니다.

- 이메일 주소, 전화번호, 비밀번호 또는 소셜 계정
- GPS 기반 정밀 위치
- 주소록, 통화 기록, SMS/MMS
- 사진, 동영상, 음성 또는 파일
- 건강, 생체, 금융 또는 결제 정보

개인정보 문의 과정에서 이용자가 이메일이나 메시지에 정보를 직접 포함하면, 개발자는 해당 문의에 답변하기 위해 그 정보를 처리할 수 있습니다.

## 2. 처리 목적

개발자는 다음 목적으로 정보를 처리합니다.

- 설치 단위 익명 인증 사용자의 생성·유지 및 인증
- 캐릭터 랭킹 등록, 조회, 무결성 점검과 삭제 동기화
- 앱 버전 확인, 공지 제공, 오류 대응과 서비스 보안
- 세션 및 진행 현황의 집계, 서비스 이용 분석과 개선
- 배너·보상형 광고 제공, 광고 성과 측정, 사기 및 무효 트래픽 방지
- 이용자 문의, 개인정보 및 법적 요청 처리

## 3. 외부 처리자와 정보 공유

개발자는 개인정보를 판매하지 않습니다. 앱 운영을 위해 다음 사업자가 정보를 처리합니다.

| 사업자 | 역할과 처리 목적 | 관련 안내 |
| --- | --- | --- |
| Supabase, Inc. | 익명 인증, 데이터베이스 호스팅, API 제공, 보안 및 장애 대응. 현재 앱 데이터베이스의 주 리전은 대한민국 서울입니다. | [Supabase Privacy](https://supabase.com/privacy) |
| Google LLC | AdMob/GMA를 통한 광고 제공·측정, 분석, 사기 및 무효 트래픽 방지. 정보가 Google의 글로벌 인프라에서 처리될 수 있습니다. | [Google Privacy Policy](https://policies.google.com/privacy) |
| Google LLC / Firebase | Remote Config 설정 제공과 설치 식별, 서비스 유지·개선. 정보가 Google의 글로벌 인프라에서 처리될 수 있습니다. | [Firebase Privacy and Security](https://firebase.google.com/support/privacy) |

Supabase는 개발자의 지시에 따라 데이터를 처리하는 서비스 제공자로 사용됩니다. Google Mobile Ads는 광고 생태계에서 위 1.3의 정보를 수집하고 공유할 수 있습니다. 법령상 의무 이행, 이용자 보호 또는 권리 방어가 필요한 경우 관련 기관에 정보가 제공될 수 있습니다.

## 4. 보유 및 삭제

| 정보 | 보유 기준 |
| --- | --- |
| 기기 내부 게임 저장·설정 | 이용자가 앱 데이터 삭제 또는 앱 삭제를 할 때까지 |
| 상세 세션 로그 | 서버에 기록된 종료 시각부터 최대 30일 |
| 일별 세션 집계 | 해당 활동일로부터 최대 90일 |
| 익명 인증 사용자, 기기·앱 프로필, 랭킹 | 익명 인증 사용자가 삭제되거나 서비스가 종료될 때까지. 공개 개인정보처리방침의 이메일 경로로 데이터 삭제를 요청할 수 있습니다. |
| 캐릭터 랭킹 | 앱에서 해당 캐릭터를 삭제하고 서버 동기화가 성공하면 삭제 |
| 광고 관련 정보 | Google의 정책과 이용자의 광고·동의 설정에 따름 |
| Firebase 설정 및 설치 정보 | 로컬 설정 캐시는 앱 데이터 삭제 시 제거되며 서버 처리·보유는 Firebase 정책에 따름 |
| 문의 내용 | 문의 처리와 분쟁 대응에 필요한 기간 동안 보유한 뒤 삭제. 법령상 보존 의무가 있으면 해당 기간 동안 보유 |

앱 삭제는 기기의 로컬 저장과 인증 토큰을 제거하지만, 이미 Supabase에 전송된 익명 인증 사용자 및 연결 데이터까지 즉시 삭제하지는 않습니다.

## 5. 이용자의 권리와 요청 방법

이용자는 자신의 정보에 대한 열람, 정정, 삭제, 처리 제한 또는 문의를 요청할 수 있습니다.

- 공개 요청 경로: [https://nullplaying.4ltree.com/data-deletion](https://nullplaying.4ltree.com/data-deletion)
- 데이터 식별 ID: 앱의 `설정 > 게임 정보 > 데이터 삭제 요청`에서 전체 ID를 확인하거나 복사할 수 있습니다.
- 이메일: [4ltree.service@gmail.com](mailto:4ltree.service@gmail.com)
- 데이터 삭제 제목 권장 형식: `NULL PLAYING 데이터 삭제 요청`
- 기타 개인정보 문의 제목 권장 형식: `NULL PLAYING 개인정보 요청`

데이터 삭제 요청에는 앱에 표시된 전체 데이터 식별 ID를 포함해야 합니다. 개발자는 해당 ID의 Supabase 익명 인증 사용자와 연결된 `user_profiles`, `ranking_entries`, `app_session_logs`, `app_session_daily` 데이터를 확인한 뒤 삭제하고, 합리적인 기간 안에 처리 결과를 회신합니다. 법령, 보안 또는 부정 이용 방지를 위해 일부 정보를 보존해야 하는 경우에는 그 사유와 보유 기간을 안내합니다. 문의 이메일과 처리 기록은 위 4절의 문의 내용 보유 기준에 따라 별도로 관리됩니다.

삭제된 익명 인증 사용자의 세션이 기기에 남아 있는 상태에서 앱을 다시 실행하면, 앱은 서버에서 기존 인증의 삭제 여부를 확인합니다. 삭제됨이 확인되면 이전 식별자에 연결된 서버 전송 대기열과 캐시를 폐기하고 새로운 설치 단위 익명 인증 사용자를 생성합니다. 기기의 로컬 게임 진행 정보는 삭제하지 않으며, 삭제 처리 후에도 앱을 계속 사용하면 새 식별자로 새로운 이용 데이터가 전송될 수 있습니다.

## 6. 안전성 확보 조치

개발자는 다음 조치를 적용합니다.

- Supabase와 Google 광고 통신에 HTTPS/TLS 사용
- Firebase Remote Config와 Installations 통신에 HTTPS 사용
- Supabase Row Level Security를 통한 설치별 데이터 접근 통제
- 앱에 공개용 키만 포함하고 관리자용 `service_role` 키는 포함하지 않음
- 랭킹 쓰기 항목 검증과 최소 권한의 서버 함수 사용
- 상세 세션 로그 30일, 일별 집계 90일의 자동 삭제 작업
- Android 시스템 백업 및 기기 이전 비활성화

인터넷 전송이나 전자 저장 방식에 절대적인 안전을 보장할 수는 없지만, 처리 목적과 위험에 맞는 보호 조치를 지속적으로 점검합니다.

## 7. 알림과 기기 권한

앱은 네트워크 연결을 위해 인터넷·네트워크 상태 권한을 사용합니다. 오프라인 모험 시간 알림은 선택 기능이며, Android 버전에 따라 알림 권한을 요청합니다. 알림을 거부해도 기본 게임은 이용할 수 있습니다.

광고 SDK와 Android 작업 스케줄러가 앱 매니페스트에 추가하는 권한이 있을 수 있습니다. 권한이 선언되어 있다는 사실만으로 개발자가 해당 정보 전체를 직접 수집한다는 의미는 아니며, 실제 외부 전송 항목은 이 방침과 Google Mobile Ads의 공개 내용을 기준으로 안내합니다.

## 8. 방침 변경

수집 항목, 외부 사업자, 보유 기간 또는 이용자 권리 행사 방법이 바뀌면 이 방침을 갱신합니다. 중요한 변경은 앱 공지 또는 이 페이지를 통해 알리고, 상단의 최종 수정일을 변경합니다.
