# 성직자 WIS/CHA 변경과 10시간 상한안

## 반영 범위

성직자의 주 능력치를 WIS, 보조 능력치를 CHA로 변경했다. `HeroClass`를 공통 기준으로 사용하는 생성 화면의 능력치 강조, 클래스 유도 성장, 주 능력치 70%/보조 능력치 30%의 전투력·피해·기본 스킬 확률 계산에 반영된다. 공통 MP 성장식인 INT/WIS 50:50은 변경하지 않았다.

기존 저장 캐릭터의 INT를 CHA로 옮기는 데이터 보정, DB 접근, 앱 실행, APK 배포는 하지 않았다. 추후 배포 시 기존 성직자의 계산상 전투력이 바뀔 수 있으므로 기존 캐릭터 보정 정책을 별도로 정해야 한다. HP/MP/DEX/CHA 추가 보너스는 아직 기획·분석용이며 운영 게임에 적용하지 않았다.

## 검증

순수 엔진/모델과 `SimpleGameEngineTest`, `ClericStatContractTest`만 별도 컴파일하여 실행했다. **113개 테스트 통과**. 생성 화면 테스트의 기대 스탯 쌍도 WIS/CHA로 갱신했지만 Compose UI 테스트나 기기 화면 검증은 실행하지 않았다. 상세 로그는 `pure-engine-tests.log`다.

네트워크와 DB 파일 접근을 차단한 엔진에서 성직자 seed 2–13의 12개 성장 경로를 다시 계산했다. 다른 다섯 직업은 동일한 소스·난수 조건의 기존 결과를 재사용했다. 전후 엔진/모델 해시를 비교하여 앱 코드 변경이 성직자 쌍을 담은 모델 파일뿐임을 확인했고, 나머지 직업 스탯 쌍은 새 회귀 테스트로 고정했다. 이전 WIS/INT 기반 결과는 상위 폴더에 보존했다.

보정 seed 2–5, 별도 비교 seed 6–13을 유지했다. 권장 HP 곡선은 96개 후보 중 종전과 동일하게 `8 + 2 × min(HP / 6000, 1)^0.8`시간이다. MP 기본 확률은 기존값에 `10 × min(MP/6000,1)`%p를 더해 최대 30%, 탐색은 `5−min(DEX/150,1)`초, 아이템 판매 보너스는 `20×min(CHA/150,1)`%로 유지한다.

## 변경 후 100레벨 평균

| 직업 | HP 보유시간 | 스킬 기본 확률 | 탐색시간 | 판매 보너스 |
|---|---:|---:|---:|---:|
| 전사 | 10시간 | 24.65% | 4.689초 | +6.53% |
| 도적 | 9시간 6분 | 24.39% | 4.001초 | +6.40% |
| 레인저 | 9시간 8분 | 28.25% | 4.000초 | +6.27% |
| 마법사 | 9시간 8분 | 30.00% | 4.686초 | +6.30% |
| 성직자 | 9시간 8분 | 28.18% | 4.686초 | +19.83% |
| 팔라딘 | 9시간 5분 | 24.66% | 4.689초 | +19.90% |

표는 직업당 8개 별도 경로에서 효과를 계산한 뒤 평균한 값이다. 변경 전 성직자는 같은 표본에서 기본 확률 30%, 판매 보너스 +6.3%였다. 새 성직자는 스킬·판매 혼합형, 마법사는 순수 스킬 특화로 구분된다. 팔라딘과 판매 보너스는 겹치지만 팔라딘의 STR 가방 용량 이점은 남는다.

## 균형 판단

같은 목표 레벨까지의 직업별 평균 소요시간 역수를 비교한 성장속도 격차는, 매번 12분 충전할 때 8시간 간격 접속 약 **2.97%**, 12시간 간격 접속 약 **5.51%**다. 같은 변경 후 직업 조합에 HP 12시간 상한을 대입하면 12시간 간격 격차는 **10.62%**다. 10시간 단순 비례식은 **5.93%**여서 권장 곡선의 추가 개선 폭은 약 0.42%p다.

성직자 변경 후 최상위/최하위 성장 직업이 바뀌지 않아 성장 격차는 유지되었다. 판매 골드/환산일의 직업 간 격차는 8시간 간격 10.60%, 12시간 간격 8.45%다. 성장속도와 판매 경제를 같은 점수로 더하지 않았다.

## 한계

- 전체 난수 공간이나 모든 가능한 공식의 전역 최적해가 아니라, 정한 후보와 표본 범위의 기획 권장안이다.
- 접속 간격은 실제 접속 이벤트 전체 재생이 아니라 시간저장량을 이용한 환산이다. 구간 상하한 차이는 100레벨에 최대 0.2653%였다.
- 비특화 HP 추가시간은 별도 표본에서 최대 76.23분으로, 보정 기준 75분을 1개 경로가 1.23분 초과했다.
- 100레벨 상한 도달은 HP 특화 8/8, MP 특화 8/8, DEX 특화 15/16, CHA 특화 13/16이다. 비특화 상한 도달은 없었으나 모든 성장운에서의 배타성과 도달을 보장하지 않는다.
- 재현 노트북 `ten_hour_review.ipynb`의 코드 셀 3개는 일반 Python에서 순서대로 실행했다. Jupyter 커널 실행은 미검증이다.

재현: `tools/analysis/run_cleric_stat_probe.py`, `tools/analysis/run_pure_engine_tests.py`, `tools/analysis/refresh_cleric_balance.py`. 입력·출력 및 현재 소스 해시는 이 폴더에 보존했다.
