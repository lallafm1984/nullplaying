# 검증 메모

판정: **조건부 기획 검토에 사용 가능 (Share with caveats)**.

- 후보 75,264개. 독립 검증은 6직업 × 4시드 × 2설정, 총 48개 성장 경로.
- 원본 엔진과 보너스 비활성 분석 사본의 시드0·레벨1/5/10/20 출력 24행을 대조해 기존 21개 필드 일치.
- dense 출력은 동일 검증 시드·추천안의 레벨별 기록이며 기존 체크포인트 288행과 전 필드 일치. 독립 시드 수에 더하지 않음.
- 기대 행 수·중복·결측·직업/레벨 커버리지·누적값 단조성·훈련/검증 시드 분리를 검사.
- 운영 소스 SHA-256이 분석 시작 기준과 같은지 검사. 분석 보너스는 별도 사본에만 주입.
- HP/MP/DEX/CHA 입력 0~10¹⁸에서 보너스 비음수·단조·상한 확인. 무한 레벨 게임 진행 검증은 아님.
- 보유 한도 480/540/600분에서 전경1분 충전·12분 완충·24시간 부재 차감·잔여0 이후 추가 부재 때 처치수 불변을 실제 엔진에서 확인.
- OS sandbox의 네트워크 차단은 localhost 연결 시 PermissionError로 확인. 어떤 외부 호스트에도 연결하지 않음.
- .sqlite 접근 차단은 DB가 아닌 일회용 텍스트 파일로 PermissionError 확인 후 해당 파일을 제거. 실제 DB를 열거나 생성하지 않음.
- 오프라인 일수 환산에 전경 체류 시간과 충전율 포함. 레벨100 적분 상·하한 차이 최대 0.148%.
- 판매 골드는 퀘스트/드롭 골드와 분리. 전체 판매 수입 증가율과 CHA 단가 증가율을 구분.
- 최종 성장 속도 지표는 실제 엔진의 동일 레벨 도달 시간. 후보 탐색의 처치량 대리 지표와 구분.
- 노트북 코드 셀 4개는 동일 Python 프로세스에서 순서대로 실행 및 출력 저장. nbformat/nbclient/ipykernel 미설치로 Jupyter 커널 검증은 미실행.
- 상위 후보 점수 차이가 작음. 현재 추천 상수의 유일성·전역 최적·실사용 효과를 주장하지 않음.
- 검증 후 파라미터를 재조정하지 않아 별도 시드 검증의 분리를 유지.
- 보고서 차트/표는 로컬 집계 출력과 연결하고 정량 주장·퍼센트 단위·비교 기준을 대조.
- 보고서 뷰어의 형식 검증은 실패: `source.query.sql`에 실제 SQL만 허용하고 Python 코드를 거부함을 뷰어 소스에서도 확인. 가짜 SQL로 출처를 바꾸지 않았으며 렌더 호출·사이트 공개를 하지 않음. `artifact.json`은 미렌더 초안으로 명시하고, 동일 숫자를 표로 보존한 REPORT.md로 대체 제공. 차트 시각 QA는 미실행.

안전한 후속 단계는 기획 상수와 8시간의 의미를 확정하는 것입니다. 실제 구현·배포·기존 잔여시간 정책은 별도 작업입니다.
