# 능력치 안내 후속 개선: 배지, 한 화면 팝업, 합계 정렬

## 변경

- 공통 안내 버튼은 높이 28dp의 둥근 배지 형태다. 화면 픽셀로 테두리 높이 74px, 터치 영역 126px(420dpi에서 약 28dp / 48dp)을 확인했다. 금색 테두리·배경·안내 아이콘과 버튼 접근성 역할을 유지한다.
- 팝업 제목 18sp, 항목·본문 12sp, 본문 줄 간격 17sp, 항목 간격 8dp로 조정했다. 기존 420dp 본문 높이 제한을 없애고 가용 화면을 사용한다. 작은 화면/확대 글자용 스크롤과 고정 닫기는 유지한다.
- 생성 화면의 합계만 우측 정렬한다. 제목과 배지는 왼쪽에서 필요할 때 줄바꿈하며 합계는 별도 우측 영역이다. 기존 카드 내부 14dp 패딩에 4dp를 더했다. 실제 UI에서 스탯 영역 우측 990px, 합계 우측 979px로 추가 여백 11px을 확인했다.
- 안내 문구, 세 언어 번역, 게임 수치, 저장/랭킹 정책은 변경하지 않았다.

## 검증

- 네트워크와 DB 파일 접근을 차단한 순수 JVM 계약 테스트 7개 통과.
- `assembleDebug`, `compileDebugUnitTestKotlin`, `compileReleaseKotlin` 성공. `git diff --check` 통과.
- 최신 APK와 설치된 APK SHA-256 일치: `3ced37662cc53192ea4b8931a8dc51a5ed865aca0769ffa3e1e8893fecd2229d`.
- `alarmquest-qa` / `emulator-5554`, Android 15, 1080×2340, 420dpi, 시스템 글자 크기 1.0에서 검증했다.
- 한국어 생성/모험가 팝업의 전체 문구 일치, 한·영·일 모두 8개 능력치와 마지막 직업 설명 및 닫기가 스크롤 없이 한 화면에 표시됨을 원본 스크린샷과 UI XML로 확인했다.
- 영어·일본어 팝업은 `e164af052a8b74f84a6d70fefed7c2a1082bed549a2cc26d8140846afa023a10` 빌드에서 촬영했다. 그 이후 변경은 팝업 밖 헤더의 합계 정렬뿐이며 팝업·번역은 동일하다. 한국어 두 진입점 및 배지/합계는 최신 빌드로 다시 촬영했다.
- 현재 에뮬레이터는 한국어·기본 글자 크기의 생성 화면이다. 임시 테스트 모험가만 앱의 확인 대화상자를 통해 영구 삭제했다. 현재 굴림은 저장하지 않았다.

## 운영 데이터 격리

- 디버그 Supabase 설정은 빈 문자열이고 서비스는 DEBUG 연결을 거부한다.
- 에뮬레이터의 기존 외부 네트워크 차단 샌드박스를 유지했다. Android 비행기 모드 ON, Wi-Fi/데이터 OFF, 라우팅 테이블이 비어 있음을 재확인했다.
- UI 검증 중 에뮬레이터 내부 임시 게임 저장은 사용했다. 운영 DB로 기기/사용자/랭킹/로그를 전송하지 않았다. 실물 기기 설치·스토어 업로드는 하지 않았다.
