# 능력치 안내: 공통 팝업과 버튼 식별성

> 후속 사용자 피드백을 반영한 최신 배지형 버튼, 한 화면 팝업, 생성 합계 우측 정렬 검증은 [COMPACT_REVIEW.md](COMPACT_REVIEW.md)를 참조한다. 아래 내용과 `*-ko-final.png`는 그 이전 버튼 버전의 기록이다.

## 반영 내용

- 모험가 메뉴의 `능력치`, 생성 화면의 `능력치 굴림` 옆에 같은 공통 버튼을 배치했다.
- 초기 텍스트만 있는 버튼이 알아보기 어렵다는 사용자 피드백을 반영하여 금색 테두리, 은은한 배경, 안내 아이콘을 추가했다. 텍스트 라벨과 최소 48dp 터치 영역을 유지했다.
- STR/CON/DEX/INT/WIS/CHA/HP MAX/MP MAX의 효과만 짧게 설명한다. 수치·계수·상한·계산식은 표시하지 않는다.
- 한국어 `능력치 안내`, 영어 `Stat Guide`, 일본어 `能力値ガイド`. 버튼/제목/본문/닫기 모두 기존 런타임 번역을 사용한다.
- 팝업 본문은 스크롤하고 닫기 버튼은 고정한다. 헤더는 공간이 부족하면 줄바꿈한다. 생성 화면에서 안내를 열 때 키보드를 닫으며, 안내 열기/닫기는 이름·굴림·저장 데이터에 영향을 주지 않는다.

## 검증

- 순수 JVM 전용 테스트 4개 통과: 표시 중인 8개 능력치 대응, 숫자 없는 간결한 문구, 영·일 전체 번역, 두 화면의 공통 UI 사용 및 저장/생성 호출 부재. 네트워크와 DB 파일 접근을 OS 샌드박스로 차단했다.
- `assembleDebug`, `compileDebugUnitTestKotlin`, `compileReleaseKotlin` 성공. 테스트의 nullable 경고도 수정 후 재컴파일했다.
- 최종 APK 및 설치된 APK의 SHA-256 일치: `6ac2408d197137bb185a439a6044f6add860184c62eadc89e9194886b017bb2c`.
- `alarmquest-qa` / `emulator-5554`, Android 15, 1080×2340, 420dpi에 데이터 유지 설치. `com.nullplaying/.MainActivity` 콜드 실행 성공.
- 초기 버튼 버전에서 영어 생성/모험가 팝업 일치, 영어·일본어 본문/하단 스크롤, 생성 이름 `GuideQA`와 굴림 합계69 및 모든 스탯 유지 확인. 본문·번역은 버튼 식별성 수정 시 변경하지 않았다.
- 최종 버튼 버전의 한국어 생성/모험가 화면 및 팝업은 `screenshots/*-ko-final.png`에 별도 기록한다. `*-final` 없는 파일은 식별성 피드백 이전 검증 증거이므로 최종 버튼 이미지로 사용하지 않는다.
- 최종 버튼 버전의 시스템 글자 크기 1.5에서 팝업 확대, 마지막 HP/MP·직업 설명까지 스크롤, 닫기 버튼 접근을 확인했다. `*large-font*` 파일은 최종 빌드의 추가 검증이다. 기존 본화면의 `fontScale=1f` 정책은 변경하지 않았다.
- 촬영 후 글자 크기는 1.0으로 복원하고 한국어 생성 화면을 열어 두었다. 테스트용 모험가는 정리했으며 새로운 모험가를 추가로 저장하지 않았다.

## DB 및 배포 경계

- 디버그 `SUPABASE_URL`과 `SUPABASE_PUBLISHABLE_KEY`가 빈 문자열이고 `isConfigured`가 DEBUG를 거부하는 것을 확인했다.
- 에뮬레이터 프로세스 자체에 외부 outbound 금지 샌드박스를 적용했다. 로컬 ADB/콘솔만 허용한다. 같은 정책에서 Firebase Installations 호스트로의 HTTPS 연결 차단을 확인했다.
- Android 비행기 모드 ON, Wi-Fi/데이터 OFF, 라우팅 테이블 비어 있음 확인. Firebase/광고 SDK는 실패 처리되며 운영 DB와 연결하지 않는다. 화면의 테스트 광고 로드 실패는 이 네트워크 차단에 따른 것이다.
- 시작 시 에뮬레이터에 모험가가 없음을 확인했고, 이번 검증에서 만든 로컬 `GuideQA`만 생성/삭제했다. 기존 사용자 모험가를 삭제하지 않았다. 운영 DB에 테스트 기기/사용자/랭킹/로그를 생성하지 않았다.
- 기기 내부 임시 게임 저장은 UI 검증 과정에 사용했다. 로컬 저장까지 없었다고 주장하지 않는다. 스토어 배포와 실물 기기 설치는 하지 않았다.

## 재현 및 파일

- `tools/analysis/run_stat_guide_tests.py`: Android를 시작하지 않는 계약 테스트.
- `tools/analysis/stat_guide_emulator_qa.py`: 명시된 에뮬레이터의 현재 UI를 조회하고, 정확히 일치하는 텍스트만 클릭하거나 원본 스크린샷을 저장한다. UI 전환 중 실패하면 이전 XML을 재사용하지 않는다.
- `tests.log`, `tests-execution.json`: 테스트 결과와 소스 해시.
- `tools/analysis/verify_stat_guide_screenshots.py`, `ui-verification.json`: 실제 UI XML의 동일 팝업, 번역 범위, 입력 유지, 확대 글자 확인 및 최종 PNG 해시.
- `screenshots/`: 원본 PNG와 당시 UI XML. 스크린샷은 생성·합성·보정한 모형이 아니다.
