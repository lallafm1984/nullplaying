# NULL PLAYING Google Ads 앱 캠페인 광고 문구

작성일: 2026-08-28

## 캠페인 운영 기준

- 구글 앱 캠페인은 헤드라인 최대 5개, 설명 최대 5개를 서로 조합해 노출한다.
- 각 문구는 단독으로 나와도 의미가 완결되도록 작성했다.
- 한국어·영어·일본어 캠페인을 분리한다. Google Ads는 입력한 광고 문구를 자동 번역하지 않는다.
- 글자 수는 한글·일본어 전각 문자를 2자로 잡는 보수적인 Google Ads 방식으로 검증했다.
- `무료`, `1위`, `최고`, `광고 없음` 같은 검증하지 않았거나 실제 게임과 다른 표현은 사용하지 않는다.

## 권장 시작 조합

이 캠페인은 Google Ads가 자동으로 자산을 조합하므로 특정 헤드라인과 설명을 묶지 않는다. 다만 현재 제작된 이미지의 소재와 맞추기 위해 다음 문구를 우선 유지한다.

- 시계·모험 이미지: `아무것도 하지 않는 RPG` / `The RPG That Plays Itself` / `何もしないRPG`
- 성장 이미지: `손대지 않아도 성장하는 RPG` / `Just Watch This RPG Grow` / `操作しなくても育つRPG`
- 장비 이미지: `지켜보기만 하는 RPG` / `An RPG You Can Simply Watch` / `見守るだけのRPG`
- 모험담 이미지: `당신 없이도 모험하는 RPG` / `Do Nothing. The RPG Goes On` / `放置するだけで進むRPG`

## 제출 전 체크

- 언어별 광고 캠페인과 언어 타겟을 일치시킨다.
- 현재 Google Play 스토어 제목과 동일한 지역별 등록정보를 연결한다.
- 각 설명은 특정 헤드라인 없이도 의미가 완결되는지 확인한다.
- 런칭 후에는 클릭률만 보지 말고 자산별 설치·전환 성과를 비교한다.
