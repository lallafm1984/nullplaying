# NULL PLAYING

플레이하지 않아도, 모험은 진행 중. 화면을 보고 있지 않은 동안의 실제 경과 시간을 전투·성장·모험담으로 이어 주는 자동 관찰형 RPG입니다.

공식 영문 브랜드는 `NULL PLAYING`, 한국어 발음 표기는 `널 플레이잉`입니다. 기존 설치와 저장 데이터의 업데이트 호환성을 위해 Android 패키지 ID `com.alarmquest`와 기존 데이터 식별자는 유지합니다.

## 현재 규칙

- 캐릭터 생성 능력치는 Progress Quest 원본과 동일한 3d6 굴림입니다.
- 레벨업하면 최대 HP는 CON, 최대 MP는 `INT 50% + WIS 50%`를 기준으로 자원 성장합니다. 추가로 직업별 주·보조 능력치 중 하나와 HP·MP를 제외한 6개 기본 능력치 중 하나가 각각 1 증가합니다.
- 작가가 쓴 24개 장이 `제1권 · 잿빛 국경`과 `제2권 · 유리 숲의 백야`를 이루며, 각 장은 5막으로 자동 진행합니다.
- 각 막의 완료 목표는 최대 1,000회이고, 제2권 완결 뒤에는 6개 원정·30개 고유 장면으로 구성된 `국경 수호록`을 순환합니다.
- 장 시작 시 세부 적 변주를 서사 난수로 한 번 확정해 저장하며, 전투·전리품 난수와 섞어서 관리합니다.
- 5막을 완결하면 레벨업과 같은 직업 중심 능력치 성장을 한 번 적용하고 다음 장으로 즉시 넘어갑니다.
- 스킬은 5레벨마다 하나씩 자동 습득하며 최대 20개입니다.
- 장비는 더 강한 아이템을 발견하면 자동 교체합니다.
- 전투력은 직업별 주능력치 70% + 보조 능력치 30%를 레벨 기준으로 환산한 `능력치 전투력`과 6부위 평균 `장비 전투력`을 기준 50:50으로 합산합니다.
- 가방 한도는 Progress Quest 원작과 동일하게 `10 + STR`이며, 전리품 하나가 한 칸을 차지합니다.
- 몬스터는 체력 수치를 갖지 않습니다. 일반·정예·보스 기본 전투시간에 대해 종합 전투력을 레벨별 기준 전투력과 비교해 60~140%로 조정합니다.
- 전투시간 동안 기본 공격 또는 보유 스킬이 발동하며, 피해 숫자와 몬스터 에너지 표시는 공격 순간에만 함께 변합니다.
- 몬스터와 아이템 이름은 조합 생성하고 최근 이름을 제외해 반복을 줄입니다.
- 지역 선택, 도감, 강화, 프리셋, 수동 정산, 백그라운드 워커는 없습니다.
- 앱 재실행 시 마지막 저장 시각부터 현재까지를 즉시 계산합니다.

## 저장 구조

Room 13의 `simple_game_state` 한 행에 현재 상태를 저장하고, 저장 직전의 정상 JSON은 별도의 원자적 백업 파일로 보존합니다. 현재본을 해석할 수 없으면 백업본으로 자동 복구하고 현재 저장을 다시 만듭니다. JSON 상태 스키마는 엔진과 모델이 하나의 버전 상수(현재 22)를 공유하며, 알려진 Room 12→13 변경은 비파괴 자동 마이그레이션을 사용합니다. 기존 저장은 변경된 막 목표에 맞춰 진행 비율을 보존합니다. 이미 반복 원정에 진입한 저장은 제2권 13장부터 이어지고, 진행 중 전투는 새 퀘스트 카탈로그로 한 번 재기준화됩니다.

## 화면

상단 자동 전투 영역은 모든 메뉴에서 유지됩니다. 하단 메뉴는 메인, 캐릭터, 장비, 가방, 퀘스트의 5개이며 스크롤 없이 고정됩니다. 퀘스트 탭은 현재 모험담의 5막 타임라인과 완결된 `지난 모험담`을 표시합니다.

상세 콘텐츠·데이터·UI 원칙은 [`QUEST_TALE_SYSTEM_PLAN.md`](QUEST_TALE_SYSTEM_PLAN.md)에 정리했습니다.
